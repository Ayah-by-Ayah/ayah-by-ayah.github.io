# Ayah by Ayah

Qur'an study, one ayah at a time: the Arabic text (IndoPak and Madani script), a revised English translation, notes, lessons, word analysis, and full grammar and iʿrāb — with write-ups in English, Bangla, Arabic and Urdu.

This repository holds the public, read-only edition. Content is written in the private editing platform and published here as `data/content.json`.

## Sources
- Arabic text: IndoPak script as published by quran.com; Madani (Uthmani) script from the Noble Qur'an Encyclopedia (quranenc.com).
- Base English translation: Saheeh International (via tanzil.net).
- Word analysis: Quranic Arabic Corpus morphology (Kais Dukes), GNU GPL.
- Sentence analysis: the Quranic Treebank by NoorBayan, MIT licence.
- IndoPak Qur'an font: Al Qalam.
